Machine learning training, from scratch¶

Train/val/test splits, loss curves, overfitting, regularisation — the things every ML course glosses over.

We start from a one-feature regression problem (learn a noisy sine), build a small MLP in PyTorch, and use it to visualise every concept that matters in training: the train/val split, the loss curve, overfitting, early stopping, weight decay, and dropout.

By the end you'll have:

  1. Written a train() loop by hand (no model.fit).
  2. Made a model overfit on purpose so you know what it looks like.
  3. Compared three regularisation knobs side by side.

1. Setup¶

We use PyTorch for the model and matplotlib for the plots. The whole notebook runs in seconds on CPU.

3. The train / val split¶

Never train on the data you evaluate on. We hold out 30 % of points as a validation set the model never sees during weight updates.

The third split — test — is what you touch once at the very end to report your final number. We omit it here because the dataset is tiny and the goal is to visualise dynamics, not benchmark.

4. The model¶

A small multi-layer perceptron (MLP): 1 → 128 → 128 → 128 → 128 → 128 → 1, Tanh activations. This is more capacity than the problem really needs — deliberately, so you can watch it overfit.

In [4]:
class MLP(nn.Module):
    def __init__(self, hidden=128, depth=5, p_drop=0.0):
        super().__init__()
        layers = [nn.Linear(1, hidden), nn.Tanh()]
        for _ in range(depth - 1):
            layers += [nn.Linear(hidden, hidden), nn.Tanh()]
            if p_drop > 0:
                layers.append(nn.Dropout(p_drop))
        layers.append(nn.Linear(hidden, 1))
        self.net = nn.Sequential(*layers)
    def forward(self, x): return self.net(x)

model = MLP(hidden=128, depth=5, p_drop=0.0)
print(model)
print('params:', sum(p.numel() for p in model.parameters()))

5. The training loop, by hand¶

for each epoch:
    forward pass     y_pred = model(X_train)
    compute loss     loss = MSE(y_pred, y_train)
    zero gradients   opt.zero_grad()
    backward pass    loss.backward()
    update weights   opt.step()

We also evaluate on the val set every step so we can plot both curves.

In [5]:
def train(model, Xt, yt, Xv, yv, epochs=3000, lr=0.01, weight_decay=0.0):
    opt = optim.Adam(model.parameters(), lr=lr, weight_decay=weight_decay)
    loss_fn = nn.MSELoss()
    tr_hist, va_hist = [], []
    for ep in range(epochs):
        model.train()
        loss = loss_fn(model(Xt), yt)
        opt.zero_grad(); loss.backward(); opt.step()
        tr_hist.append(loss.item())
        model.eval()
        with torch.no_grad():
            va_hist.append(loss_fn(model(Xv), yv).item())
    return tr_hist, va_hist

tr_o, va_o = train(MLP(128, 5), Xt, yt, Xv, yv, epochs=3000, weight_decay=0.0)
print(f'final train MSE {tr_o[-1]:.4f}   final val MSE {va_o[-1]:.4f}')

final train MSE 0.0059   final val MSE 0.0532

6. Reading a loss curve¶

The two curves tell different stories. Train loss falling means the optimiser is doing its job. Val loss is the only thing that tells you whether the model is learning the world or just memorising the training set.

The point where val loss starts climbing is the point you want to stop training — early stopping.

In [6]:
best_ep = int(np.argmin(va_o))

fig, ax = plt.subplots(figsize=(6, 3.5))
ax.plot(tr_o, label='train', lw=1.5)
ax.plot(va_o, label='val',   lw=1.5)
ax.axvline(best_ep, color='gray', ls='--', lw=1)
ax.text(best_ep+30, max(va_o)*0.7, f'early-stop @ ep {best_ep}', color='gray', fontsize=9)
ax.set_yscale('log'); ax.set_xlabel('epoch'); ax.set_ylabel('MSE (log)')
ax.set_title('Overfitting: val loss climbs while train loss falls')
ax.legend(frameon=False); plt.tight_layout(); plt.show()

7. Three knobs that fix overfitting¶

knob what it does when to reach for it
early stopping Stop when val loss stops improving. Always — free.
L2 / weight decay Penalise large weights in the loss function. When val plateaus high.
dropout Randomly zero activations during training. Deeper nets, larger data.

A fourth knob — reduce model capacity — is the most underused. If your model still overfits with the others on, try a smaller network.

In [7]:
tr_r, va_r = train(MLP(128, 5), Xt, yt, Xv, yv, epochs=3000, weight_decay=1e-3)
tr_d, va_d = train(MLP(128, 5, p_drop=0.1), Xt, yt, Xv, yv, epochs=3000)

fig, ax = plt.subplots(figsize=(6.5, 3.6))
ax.plot(va_o, label='no reg',      lw=1.5)
ax.plot(va_r, label='L2 (1e-3)',   lw=1.5)
ax.plot(va_d, label='dropout 0.1', lw=1.5)
ax.axvline(best_ep, color='gray', ls='--', lw=1, label='early-stop point')
ax.set_yscale('log'); ax.set_xlabel('epoch'); ax.set_ylabel('val MSE (log)')
ax.set_title('Validation loss with three regularisers')
